# Уроки проекта AmneThron: сборка Win64

Уровень: **project**. Формат — см. `self-learning-core/references/lesson-format.md`.

Сюда записываются подтверждённые уроки после исправления ошибок сборки, инсталлятора,
рантайма и публикаций AmneThron на Windows. Правила, верные для всей машины или других проектов,
поднимаются на уровень machine (`%USERPROFILE%/.codex/skills/`) с согласия человека.

### L-20260930-1: Предотвращение дублирования публикаций в Telegram при асинхронной отправке
- Триггер: отправка сообщений/анонсов через Telegram Web CDP / UI автоматизацию
- Было: после первого клика по отправке скрипт сразу проверил DOM; из-за задержки рендера нового бабла решил, что сообщение не ушло, и кликнул повторно, создав дубликат в теме
- Причина: Telegram Web K обновляет DOM баблов с небольшой асинхронной задержкой (до 1-2 сек). Быстрая проверка DOM сразу после клика даёт ложноотрицательный результат
- Стало: после отправки ждать очистки поля ввода (`inputText === ''`) и появления нового бабла с таймаутом до 3-5 секунд; ни при каких условиях не слать повторный клик вслепую без проверки `isOut` баблов по `mid` или тексту в истории
- Проверка: убедиться, что в чате присутствует ровно один бабл с текстом анонса (`bubbles.filter(b => b.hasTarget).length === 1`)
- Уровень: project
- Сигнатура причины: verification.async-dom-delay
- Дата: 2026-09-30

### L-20261017-1: Остановка на staging/portable при исправлении багов и отладке подключений
- Триггер: исправление ошибки подключения, протокола или логики по запросу пользователя
- Было: после успешной компиляции и смоук-теста агент сразу запустил `build-installer.ps1` для сборки дистрибутива, не дав человеку проверить работоспособность программы в UI
- Причина: некритичное следование устаревшей политике `Default Completion Policy`, требовавшей непрерывного перехода от сборки к инсталлятору и релизу
- Стало: при исправлении ошибок, доработке протоколов и отладке подключений всегда останавливаться на portable/staging (`deployment\windows-amd64\`), проводить смоук-тест и передавать результат человеку для подтверждения; сборку инсталлятора запускать только после подтверждения или по прямому запросу
- Проверка: убедиться, что `deployment\windows-amd64\Throne.exe` и `ThroneCore.exe` актуальны и работают, а процесс сборки инсталлятора не запускается автоматически
- Уровень: project
- Сигнатура причины: workflow.premature-installer-build
- Дата: 2026-10-17


### L-20261018-1: Запуск и осмотр Throne через computer-use
- Триггер: нужно запустить Throne, посмотреть его окно, диалог или лог
- Было: `open_application "Throne"` запустил установленный `C:\Program Files\Throne` (админ, TUN + системный прокси) рядом со staging; он упал на занятом порту 5533 с диалогом `LoadConfig return error`, человек решил, что агент включил TUN. Скриншоты при этом сворачивали окно Claude, а первый снимок был с другого монитора
- Причина: правило «запускать только staging» было, но computer-use выбирает приложение по имени, а не по пути; проверки, какой exe реально открыт, не было
- Стало: staging запускать только `Start-Process` по полному пути; состояние окон, диалогов и лога читать через PowerShell/UI Automation (`AutomationElement` по ProcessId); computer-use — только если иначе нельзя, с `switch_display` на монитор, где окно (по `BoundingRectangle`)
- Проверка: `Get-Process Throne | Select Path` — все пути внутри `deployment\windows-amd64`
- Уровень: project
- Сигнатура причины: tooling.name-resolves-wrong-binary
- Дата: 2026-10-18

### L-20261018-3: Установщик релиза — ещё и на Яндекс.Диск
- Триггер: публикация нового установщика AmneThron
- Было: по `installer.md` установщик публиковался только в GitHub Releases, копирование на Яндекс.Диск было запрещено
- Причина: прежнее решение владельца сменилось; правило в навыке устарело
- Стало: после релиза копировать `ThroneSetup-<version>.exe` в `D:\YandexDisk\Install\Net\vpn\AmneThron` и сверять размер/хэш копии
- Проверка: `Get-FileHash` копии равен SHA-256 из GitHub Release
- Уровень: project
- Сигнатура причины: workflow.stale-publish-target
- Дата: 2026-10-18
